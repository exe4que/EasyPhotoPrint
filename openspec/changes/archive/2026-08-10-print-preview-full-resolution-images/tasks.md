## 4. Print-resolution hook

- [x] 4.1 Add `src/hooks/usePrintResolutionSrc.ts` exporting `usePrintResolutionSrc(asset: ImageAsset, widthMm: number, heightMm: number, dpi: number): string | undefined`. Computes `minWidthPx`/`minHeightPx` via `mmToPx(widthMm, 1, dpi)` / `mmToPx(heightMm, 1, dpi)`, checks a module-level `Map<string, string>` cache keyed by `` `${asset.storedPath}::${Math.round(minWidthPx)}x${Math.round(minHeightPx)}` ``, returns the cached entry immediately if present. If not cached (and `asset.missing` is not true — no point decoding a file that's already known unreadable), kicks off `getEppApi().images.decodeAtSize(asset.storedPath, minWidthPx, minHeightPx)` in a `useEffect` keyed on the cache key, stores the resolved data URL in the cache and in local state on success, and returns `undefined` while pending or on `asset.missing`. **Refinement over the plan**: the hook returns `printResolutionCache.get(cacheKey)` read directly at render time (not a `useState` holding the resolved URL) — a `useState`-held value would go stale if the same hook instance is reused for a different asset/size across renders (the effect only fires on cache-key change, but state doesn't auto-reset), so the effect's only job is populating the cache and forcing a re-render; the actual returned value always reflects the *current* cache key.
